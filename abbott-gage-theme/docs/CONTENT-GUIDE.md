### Process Details

```
When you send equipment to our laboratory, it undergoes a comprehensive calibration process:

1. **Inspection:** Each item is carefully inspected upon arrival
2. **Cleaning:** Equipment is cleaned as needed
3. **Initial Measurement:** Pre-calibration measurements are recorded
4. **Calibration:** Adjustments made using NIST-traceable standards
5. **Verification:** Post-calibration verification ensures accuracy
6. **Documentation:** Complete certification provided with traceability
7. **Return:** Equipment carefully packaged and returned

Turnaround time: Typically 3-5 business days
```

## Image Optimization

### Image Guidelines

- **File Format:** JPG for photos, PNG for logos/graphics
- **File Size:** Optimize to under 200KB when possible
- **Dimensions:** Maximum width 1920px
- **Alt Text:** Always include descriptive alt text
- **File Names:** Use descriptive names (micrometer-calibration.jpg)

### Required Images

1. **Hero/Header Image** - High-quality lab or equipment photo
2. **Logo** - Transparent PNG, minimum 300x80px
3. **Certification Badges** - ISO, WBENC, WOSB logos
4. **Equipment Photos** - Various measuring tools
5. **Manufacturer Logos** - All partner brands
6. **Facility Photos** - Lab, workspace (optional)
