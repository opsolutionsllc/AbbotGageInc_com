## 🔐 NAP Consistency Rules

**NAP = Name, Address, Phone**

### ALWAYS Use Same Format:
- **Name:** "Abbott Gage, Inc." (with comma and period)
- **Address:** "40 Industrial Park, Childersburg, AL 35044"
- **Phone:** "(256) 378-3286" (with parentheses and dash)

### Use Shortcodes:
- ✅ DO: `[business_phone]`
- ❌ DON'T: Manually type phone number

## 🛠️ Quick Troubleshooting

### Schema Not Showing?
- Wait 4-6 weeks for Google
- Submit sitemap to Search Console
- Request indexing

### Shortcode Not Working?
- Check ACF Options page
- Verify field names match
- Clear site cache

### Map Not Displaying?
- Add Google Maps API key
- Check map embed code
- Verify domain restrictions

### Wrong Info Showing?
- Update ACF Options
- Clear cache
- Check for hard-coded values
