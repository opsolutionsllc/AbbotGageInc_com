# Installing Advanced Custom Fields (ACF) Plugin

**⚠️ This theme requires ACF to function!** Without it, content will not display properly.

---

## What is ACF?

Advanced Custom Fields (ACF) is a **free WordPress plugin** that allows you to create custom fields for editing content. This theme uses ACF to make all content easily editable through the WordPress admin panel.

**No coding knowledge required!**

---

## Installation Steps

### Method 1: From WordPress Admin (Recommended)

1. **Log into WordPress Admin**
   - Go to: `yoursite.com/wp-admin`

2. **Navigate to Plugins**
   - Click: **Plugins → Add New**

3. **Search for ACF**
   - In the search box, type: `Advanced Custom Fields`

4. **Find the Correct Plugin**
   - Look for the plugin by **Delicious Brains**
   - It should say "Advanced Custom Fields" with 2M+ active installations
   - **Make sure it's the free version** (not ACF PRO)

5. **Install & Activate**
   - Click: **Install Now**
   - Wait for installation to complete
   - Click: **Activate**

6. **Verify Installation**
   - You should now see **"Theme Settings"** in your admin menu
   - The admin warning notice should disappear

---

### Method 2: Manual Installation

1. **Download ACF**
   - Go to: https://wordpress.org/plugins/advanced-custom-fields/
   - Click: **Download**

2. **Upload to WordPress**
   - Go to: **Plugins → Add New → Upload Plugin**
   - Choose the downloaded ZIP file
   - Click: **Install Now**
   - Click: **Activate**

## Troubleshooting

### "Plugin not found"
- Make sure you're searching for the exact name: "Advanced Custom Fields"
- Check that you have admin access to install plugins
- Try Method 2 (manual installation)

### "Theme Settings not appearing"
- Verify ACF is **activated** (not just installed)
- Go to: **Plugins → Installed Plugins**
- Look for "Advanced Custom Fields" - it should say "Active"
- If it says "Inactive", click "Activate"

### "Fields not showing"
- Make sure you're using the **free version** of ACF (not PRO)
- The free version is all you need for this theme
- Clear your browser cache: Ctrl+F5 (Windows) or Cmd+Shift+R (Mac)

### Still Having Issues?
- Check WordPress requirements: WordPress 5.8+, PHP 7.4+
- Try deactivating other plugins temporarily
- Contact your website developer
