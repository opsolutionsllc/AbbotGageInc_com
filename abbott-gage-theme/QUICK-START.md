# Quick Start Guide - Abbott Gage Inc Theme

Get your Abbott Gage Inc website up and running in 30 minutes!

---

## Overview

This theme includes everything you need for a professional precision measuring tools and calibration services website, including:

✅ Modern, responsive design  
✅ Pre-built page templates  
✅ SEO optimization  
✅ Mobile-friendly navigation  
✅ Contact form integration  
✅ Manufacturer showcases  
✅ Service pages  

---

## Step 1: Installation (5 minutes)

### Upload Theme

1. Compress `abbott-gage-theme` folder to a ZIP file
2. Go to WordPress Admin → **Appearance → Themes**
3. Click **Add New** → **Upload Theme**
4. Select the ZIP file and click **Install Now**
5. Click **Activate**

✅ **Theme activated!**

---

## Step 2: Install Required Plugins (5 minutes)

Go to **Plugins → Add New** and install:

1. **Contact Form 7** - For contact forms
2. **Yoast SEO** - For SEO optimization

**Optional but recommended:**
- WP Mail SMTP (email delivery)
- WP Super Cache (performance)
- Wordfence Security (security)

✅ **Plugins installed!**

---

## Step 3: Basic Settings (5 minutes)

### Permalinks
1. Go to **Settings → Permalinks**
2. Select **Post name**
3. Click **Save Changes**

### Reading Settings
1. Go to **Settings → Reading**
2. Select **A static page** for homepage
3. Choose your homepage (create if needed)
4. Click **Save Changes**

✅ **Settings configured!**

---

## Step 4: Create Pages (10 minutes)

Create these pages (just title, content comes later):

**Required Pages:**
1. Home
2. About
3. Services
4. Laboratory Calibration
5. Onsite Calibration
6. Repair Services
7. Sales
8. Manufacturers
9. Contact
10. Privacy Policy

**Quick Method:**
- Create all at once with just titles
- You'll assign templates and add content next

✅ **Pages created!**

---

## Step 5: Assign Page Templates (3 minutes)

Edit each page and assign templates:

- **Home** → Template: "Homepage"
- **Services** → Template: "Services Overview"
- **Laboratory Calibration** → Template: "Laboratory Calibration"
- **Onsite Calibration** → Template: "Onsite Calibration"
- **Contact** → Template: "Contact Us"
- **All others** → Template: "Default Template"

✅ **Templates assigned!**

---

## Step 6: Set Up Menus (5 minutes)

1. Go to **Appearance → Menus**
2. Create menu named "Primary Menu"
3. Add pages in this order:
   - Home
   - About
   - Services
     - Laboratory Calibration (sub-item)
     - Onsite Calibration (sub-item)
     - Repair Services (sub-item)
   - Sales
   - Manufacturers
   - Contact
4. Assign to "Primary Menu" location
5. Click **Save Menu**

**Repeat for "Footer Menu"** (same pages, no sub-items)

✅ **Menus created!**

---

## Step 7: Upload Logo (2 minutes)

1. Go to **Appearance → Customize**
2. Click **Site Identity**
3. Click **Select Logo**
4. Upload your logo (recommended: 300x80px PNG)
5. Click **Publish**

✅ **Logo uploaded!**

---

## Step 8: Configure Contact Form (5 minutes)

1. Go to **Contact → Add New** (Contact Form 7)
2. Copy form code from: `docs/CONTACT-FORM-7-SETUP.md`
3. Paste in form editor
4. Configure mail settings (your email)
5. Save form and copy shortcode
6. Edit Contact page
7. Replace placeholder with your shortcode
8. Update page

✅ **Contact form ready!**

---

## Step 9: Test Your Site

Visit your website and check:

- [x] Homepage displays correctly
- [x] Menu navigation works
- [x] All pages are accessible
- [x] Contact form displays
- [x] Mobile view looks good
- [x] Footer shows correctly

✅ **Site is live!**

## Support

**Theme Files Location:**
```
/wp-content/themes/abbott-gage-theme/
```

**Common Issues:**

**Menu not showing?**
- Ensure menu is assigned to "Primary Menu" location

**Contact form not displaying?**
- Check Contact Form 7 plugin is activated
- Verify shortcode is correct in page

**Styling looks off?**
- Clear browser cache
- Clear WordPress cache (if using caching plugin)
- Check CSS files are loading

**Need Help?**
- Review documentation in `docs/` folder
- Contact your development team
- Check WordPress support forums

## Quick Commands

**Clear Cache:**
- Browser: Ctrl+Shift+Delete (Windows) or Cmd+Shift+Delete (Mac)
- WordPress: Go to caching plugin settings

**Find Theme Files:**
- FTP/File Manager: `/wp-content/themes/abbott-gage-theme/`

**Update Theme:**
1. Export database backup
2. Download current theme as backup
3. Upload new theme version
4. Test thoroughly
